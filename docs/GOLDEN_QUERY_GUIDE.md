# Golden Query Guide

## 目的

`qa/golden_queries.yaml` は、RAG検索・回答品質を人間が回帰確認するための代表質問セットです。

まだ自動評価器は前提にしません。まずは、検索結果やAI回答が期待する根拠ファイルに到達し、最低限含めるべき事実を落としていないかを確認します。

## 使い方

1. `qa/golden_queries.yaml` から質問を1件選ぶ。
2. RAG検索またはAI回答を実行する。
3. `expected_source_files` に書かれた実在ファイルが根拠として参照されているか確認する。
4. `must_include_facts` の内容が回答に含まれているか確認する。
5. 足りない根拠や事実があれば、チャンク分割、索引、プロンプト、検索条件を見直す。

## 定義項目

| 項目 | 意味 |
|---|---|
| `id` | 代表質問の識別子 |
| `question` | RAGへ投入する質問 |
| `expected_source_files` | 回答根拠として参照されるべき実在ファイル |
| `must_include_facts` | 回答に最低限含めたい事実 |

## 注意

- `expected_source_files` は、このリポジトリ内に実在するファイルだけを記載します。
- `must_include_facts` は、厳密な回答文そのものではなく、落としてはいけない確認観点です。
- 公式PDFが一次情報です。この質問セットは、公式PDFの代替ではありません。
- コマンド仕様値や実機送信用の完成Hexを増やす目的では使いません。

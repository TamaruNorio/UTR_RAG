## 2. 社内共有文面

Release URL:
https://github.com/TamaruNorio/UTR_RAG/releases/tag/utr-s201-ai-v006-r9-7-external-review-candidate.1

本成果物は no-PDF package です。日本国内向け、日本語利用者向け、日本の電波法準拠機器向けのレビュー候補として整理しています。

重要な位置づけとして、これは正式社外公開版ではありません。正式RC、顧客提供版、本番利用保証版、PDF正本の代替でもありません。また、海外販売・海外運用向けではありません。

今回のv006では、UTR-S201の通信仕様、安全条件、実機確認結果、自然言語からの要件確認、多言語実装支援、複数生成AI対応、構造化コマンドカードを、AIが参照しやすい形に整理しました。ChatGPT専用、Python専用ではなく、ChatGPT、Gemini、Claude、Copilot、Cursor、社内AIなどの利用を想定しています。実装言語もPythonだけでなく、C#、C++、JavaScript、PowerShellを想定範囲に含めています。

コマンドについては、R8-7で抽出した38コマンドを1コマンド1カード形式で整理しました。AIが依頼を受けてすぐコードを書くのではなく、目的、接続方式、読み取り条件、タグ条件、安全上の制約を確認質問として返す方針にしています。

安全面では、Level 4以上の操作は明示確認が必要です。Level 5操作は、明示承認と復旧手順がない場合はHOLDです。完成Hex、SUM計算済みコマンド、実機送信用コードは含めていません。

一方で、HOLD事項は残っています。正式社外公開は社内承認待ちであり、PDF原本との全件再照合、traceability不足項目の補完、ライセンス/IP方針の最終確定、UHF_Read standalone、全38コマンドの個別実機送信確認、Level 4以上/Level 5操作の扱い、海外利用・海外販売対象外の明確化が継続事項です。

社外レビューに出す前に、表現、共有範囲、サポート境界、安全上の注意、ライセンス/IP観点について社内確認をお願いします。

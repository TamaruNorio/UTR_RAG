**GQ-017**  
正常なタグ0枚として扱えません。code1=68hはアンテナ断線検知時のエラー（CMD_ANT_ERROR）です。正常に読み取りを終えて0枚だった場合は、読取枚数0の完了ACKが返ります。今回は異常として扱い、アンテナ接続を確認してください。  
出典：7.6 紙面p.317、7.5「読み取り完了レスポンス」紙面pp.263–264。

**GQ-024**  
いいえ。サイクル通知の設定は自動読み取りモードでのみ有効です。単発Inventory／InventoryReadは、タグデータ応答後に完了ACKが返り、読み取れなかった場合も完了ACKのみが返ります。通知OFFを理由に完了ACKを省略して成功判定できません。  
出典：7.4「自動読み取りモード時の読み取りサイクル終了時のレスポンス」紙面p.234、7.5 紙面pp.263–264、268–269。

**GQ-025**  
取り除けません。TID付加OFFでも、TID長を示すn3（tid_length）の1バイトは残り、値は00hです。省略されるのはTID本体です。単発InventoryReadではコマンド内のTID付加設定を参照します。  
出典：3.9 紙面p.59、7.5「RFタグデータのレスポンス」紙面p.268。

**GQ-048**  
DATA中の03h／0Dhだけでは区切れません。データ長から全長「データ長＋7」を求め、所定位置のETX・SUM・CRを確認します。受信途中というだけでは直ちに不正と断定せず、残りの受信を待つ扱いになります。待機期限は提示資料では不明です。  
出典：5.2 紙面p.99、5.3 紙面p.100。

**GQ-049**  
エラーではありません。加算結果の下位1バイトを使うため、13FhならSUMは3Fhです。計算範囲はSTXからETXまでで、範囲内の予約バイトも含めます。SUM自身とCRは含めません。  
出典：5.3 紙面p.100、5.2 紙面p.99、7.4.23の予約バイト配置は紙面p.226。

**GQ-056**  
使えません。UTR-SUN02-4CHのROM Ver.2.052以前は下限10ms、Ver.2.100以降は下限1msと明記されています。したがって2.052の設定範囲は10～4000msです。キャリア送信時間は自動読み取り時の連続出力最大時間の設定です。  
出典：7.4「キャリア送信時間」紙面p.218。

**GQ-099**  
DATA[1]を0始まりの添字でいうなら、値は1ではなく02hです。要求の読み取り量はWord単位ですが、応答DATA[1]はバイト数です。1 Word＝2バイトなので、応答DATAは「15h 02h ［読取データ2バイト］」となります。  
出典：7.5.3 紙面pp.271–273。

**GQ-111**  
分かりません。設定ACKはリーダライタへのAccessパスワード設定の応答で、タグ認証結果ではありません。設定値は読戻し不可です。非ゼロ設定後、Read等の対象コマンドでAccessが発行されます。InventoryReadは発行しません。設定はRAM値で、再起動・電源再投入時にゼロへ戻ります。  
出典：7.4.23 紙面pp.226–227、7.5.3 紙面pp.271–272。

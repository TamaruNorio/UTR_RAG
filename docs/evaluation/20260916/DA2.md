**GQ-017**  
いいえ。code1=68hはCMD_ANT_ERRORで、アンテナ断線検知時のRFタグ通信コマンドに対するエラーです。正常な読み取り0枚とは区別し、アンテナ接続を確認してください。正常に0枚で終了した場合は、読み取り枚数0の完了ACKが返ります。  
出典：§7.6 紙面p.317、§7.5 紙面pp.263–264。

**GQ-024**  
いいえ。サイクル終了通知の設定は「自動読み取りモード」の場合に有効です。単発InventoryとInventoryReadでは、タグデータ応答の後に完了ACKが返り、読み取れなかった場合も完了ACKだけが1回返ります。通知OFFを理由に、完了ACKを待たず成功とは扱えません。  
出典：§7.4 紙面p.234、§7.5 紙面pp.263–264、268–269。

**GQ-025**  
いいえ。TID付加OFFでも、tid_lengthに相当するn3の1バイトは残り、値が00hになります。省略されるのはTID本体です。データ長は7+n1+n2+n3で、OFF時の実例にもETX直前にn3=00hがあります。  
出典：§3.9 紙面p.59、§7.5 紙面p.268。

**GQ-048**  
DATA中の03h・0Dhでは区切れません。データ長から全長「データ長＋7」を求め、所定位置のETX・SUM・CRを確認します。途中受信だけでは直ちに不正と断定できず、残りの受信が必要です。待機期限や途中受信の打切り条件は、提示資料には記載がありません。  
出典：§5.2 紙面p.99、§5.3 紙面p.100。

**GQ-049**  
エラーではありません。加算結果13Fhの下位1バイト、3FhをSUMとします。計算範囲はSTXからETXまでの全バイトで、両端を含みます。その範囲内の予約バイトも含め、SUM自身とCRは含めません。  
出典：§5.3 紙面p.100、§5.2 紙面p.99、予約バイトの例：§7.4.23 紙面p.226。

**GQ-056**  
使えません。UTR-SUN02-4CHのROM Ver.2.052以前は、キャリア送信時間の下限が10msです。1msになるのはVer.2.100以降です。この設定は自動読み取り時の連続出力最大時間で、コマンドモードでは実行終了時にキャリアOFFとなります。  
出典：§7.4「キャリア送信時間」紙面p.218。

**GQ-099**  
いいえ。DATAを0始まりで数えるなら、DATA[0]は15h、DATA[1]は読み取りデータのバイト数です。1 Word＝2バイトなので、1 Wordの読み取り成功時はDATA[1]=02hです。外側のデータ長はn+2＝04hになります。  
出典：§7.5.3 紙面pp.272–273。

**GQ-111**  
いいえ。設定ACKはリーダライタへのAccessパスワード設定に対する応答で、タグの認証成功を示しません。非ゼロ設定後、UHF_Read等の対象コマンド実行時にAccessが発行されます。設定したパスワードは読み取り不可で、ACKにも含まれないため、読戻し一致は確認できません。  
出典：§7.4.23 紙面pp.226–227、§7.5.3 紙面pp.271–272。

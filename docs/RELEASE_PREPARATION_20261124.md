# 成果保存と公開前差分の整理

本書は公開準備時点のローカル保存記録である。その後、保守者がプッシュ・マージを依頼した。公開範囲と公開用の追加調整は [公開整理記録](GEN2_PUBLICATION_20261124.md) を参照する。ここに挙げたbundle・ZIP・個別一覧は保守者のローカル保存物で、このリポジトリのcloneには含まれない。

確認日: 2026-11-24。今回の範囲は成果の保存と公開前差分の整理まで。文書検査器の追加実装、仕様の訂正確定、GitHubへの公開は含まない。

## 1. 実装成果の保存

UTR_RAGの隣にある `UTR_Offline_Frame_V1/` を独立したローカルGitリポジトリにした。ブランチは `codex/offline-frame-v1`、保存コミットは `66ccfe56291acaeb8fc10f592fc460cb2ff91c6a`。18ファイルにコード、試験、設計根拠の識別情報、独立レビュー、保存手順を含めた。改行変換を抑止して、検証済みファイルのSHA-256を維持する。

コードの配布単位は独立リポジトリとし、UTR_RAG本体に通信プログラムを取り込まない。ローカル受渡し用のGit bundleとZIPを、両リポジトリと同階層の `UTR_release_preparation_20261124/` へ保存する。外部配布前には、証跡にある端末パスの表記、参照資料の受渡し、ライセンスの適用範囲を整理する。GitHubのremoteは未設定。

## 2. 公開版と手元版の関係

origin/mainを取得し、公開基準が `0e312e52e6809643c59934daea7c5a4fc7660cb5` のままであることを確認した。手元HEADは `9b6aee1aeb2c02d79056df792f2624add028137e`。手元はマージコミット1件分後ろだが、両コミットのファイルツリーは一致する。既存変更を保持するため、作業ブランチへのmerge・reset・一括追加は行わない。

整理開始時の差分は、追跡済み84ファイル、未追跡59ファイル。追跡済みの全84ファイルと、未追跡の文書・評価資料27ファイルを公開レビューの候補にする。残り32ファイルは今回の公開対象外とする。本記録1ファイルを加えた候補は112ファイル。既存の引継ぎ記録は候補内で更新する。

| 区分 | 選定 | 次に確認すること |
|---|---|---|
| 入口・利用方針・索引・確認状態 | 公開レビュー候補 | 新規文書を含む参照先と同時に扱い、古い実機PASSを拡張しない |
| コマンドカード・共通仕様・原典照合 | 公開レビュー候補、仕様差分の確認が必要 | メタデータだけの変更と決めつけず、値・説明・保留事項を原典照合記録と確認 |
| 第2世代の設計・棚卸し・実装報告・引継ぎ | 公開レビュー候補 | 設計履歴と現在の実装状態、隣接する実装成果の所在を区別 |
| 質問集・小規模比較・評価記録・テンプレート | 公開レビュー候補 | 合成例と原典例の出典、限定評価の範囲、一般的な性能保証との混同を確認 |

「候補」は公開承認や仕様適合の宣言ではない。OPEN事項の解決、54カードの全項目照合、実機適合は今回新たに完了扱いにしない。公開する際は、入口と新規参照先をまとめたレビュー用変更として扱う。

## 保存した一覧と復元用資料

ローカル保存フォルダに次を置く。個別ファイルの判定・SHA-256・公開mainとの差・機械検索の要確認箇所は `inventory.json` と `INVENTORY.md` を正とする。機密値そのものを一覧へ転載しない。

- `UTR_Offline_Frame_V1.bundle` / `.zip`: 同じ実装コミットの履歴と追跡ファイル。
- `UTR_RAG_history.bundle`: 整理時点のGit履歴。ローカル保管用で、公開配布物ではない。
- `UTR_RAG_candidates.zip`: 今回選定した112ファイルの実byte。新規文書も含む。単独の完全リポジトリではなく、基準HEADのチェックアウトへ重ねるための保存物。
- `UTR_RAG_candidates.patch`: 公開mainからの追跡ファイルの変更。未追跡文書は含まれないため、このpatchだけで全成果を復元しない。
- `reviewed_sources.zip`: 実装時の資料スナップショットに列挙した21資料の実byte。SHA-256と照合して保存。
- `checks.json` / `checksums.json`: 整理時の検査結果と保存物のハッシュ。

同じ端末内の保存であり、端末故障に備える別媒体へのバックアップではない。対象外32ファイルと無視対象のローカルデータは、この保存パッケージへ取り込まない。元の場所に保持する。

## 保存後の確認結果

既存のfrontmatter検査54カード、文書リンク検査88文書、公開mainとの差分の空白検査に合格した。2つのbundleの整合を検査し、実装bundleを別フォルダへcloneした。18追跡ファイルが元の実byteと一致し、復元先で26テストが合格した。ZIP内の公開候補112ファイルも一覧のハッシュと一致し、対象外32ファイルは含まれていない。

候補内の代表的な認証トークン・秘密鍵・IPv4形式・端末絶対パスを機械検索した。IPv4形式の1件は原典の章番号であり、実IPではなかった。これは全本文の公開可否、タグ値の由来、顧客情報の不在を保証する検査ではない。今回対象外のコードやWord・ZIPは公開審査していない。

次工程は、公開候補の仕様差分と保留事項をレビューし、公開用ブランチで候補を選択してコミットすること。その後に文書検査器の拡張を扱う。本体の既存作業は作業ツリーに保持し、空だったステージング領域は変更していない。

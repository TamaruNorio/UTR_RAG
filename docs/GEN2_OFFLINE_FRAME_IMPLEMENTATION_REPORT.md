## 実装したもの

この記録は保守者のローカル成果の要約である。実装コード・試験ログ・独立AIレビュー全文はこの公開リポジトリには含まれず、外部配布先も未設定。公開読者が本リポジトリをcloneするだけで再実行できる試験として扱わない。

配置先はUTR_RAGの隣の独立フォルダ `../UTR_Offline_Frame_V1/`。UTR_RAGの主知識をdocs/currentとする原則を維持し、既存src/tests/GUI・USB/LANサンプルを流用・上書きしなかった。

共通フレームの分割／連結、LEN・ETX・CR・SUM検査、設定可能な100msの候補入力間隔、同期feed/poll/finish、注入時計、不変イベント、1 byte再探索、未完候補の期限／終了時全破棄を実装した。USB/COM・LAN/TCP、実機送信、要求照合、応答timeout、タグ・ACK/NACKの意味解析は含めない。

100ms・API・再同期の推奨案は、今回の実装依頼に対応する契約として採用した。公式PDFのp.98〜100を画像で再確認し、実装後にも固定値と位置・計算範囲を照合した。対象機種・ROMの取得や未確認仕様の推測は行っていない。

Windows 11 Pro x64（10.0.26300）で、CPython 3.12.10と3.14.4の両方に対し26テスト・34,520サブテストが合格した。試験は合成受信データと制御時計を使い、実時間待ちや実機接続を行っていない。

独立レビュー担当は実装担当とは別のAIエージェントである。外部の人間専門家による監査や認証と同一視しない。評価の確定内容とコード識別情報は納品先の `docs/independent_review.md` に記録する。初回は23テストの独立再実行後に利用枠のエラーで中断したが、継続指示で再開した。

独立評価は完了し、修正必須の再現可能な不具合指摘は0件。全LENの分割34,176通りと独立参照モデル比較320,000操作が一致し、再同期後の期限起点・SUMが制御値となるケースも通過した。再現用ソース、seed、結果JSON、対象コードのSHA-256を納品先に保存した。出力メモリの入力比例、誤同期・未完候補破棄による損失、実機・意味解析が非対象であることを残リスクとして明記している。

## 18項目と残る範囲

独立レビューの推奨に基づき、再同期後の期限起点、SUMが制御値になる3例、全LEN・全ADRの34,176分割を通常回帰試験へ追加した。製品コードは変更していない。主な対応はG2-03・06・07・10・11・12・13で、詳細は納品先の `docs/evidence.md` に記録した。初回レビューの対象と今回追加した試験の評価を識別するため、初回の証跡は履歴として保持する。

追加試験の独立評価も完了し、26テスト・34,520サブテストの再実行に合格、修正必須指摘は0件だった。LENとADRは各256値を網羅するが全組合せではない。評価対象のハッシュと再現スクリプトを納品先の `docs/review/delta_results.json`、`docs/review/run_delta_review.py` に保存した。

18項目の個別対応は納品先の `docs/evidence.md` に記録した。G2-09の逐次要求管理、G2-15の範囲B/Cは今回非対象／原定義未提示のまま残す。実機の100ms適合、性能保証、他OS、並行・再入動作は保証しない。文書検査器の拡張案（DOC-01〜05）は今回実装していない。

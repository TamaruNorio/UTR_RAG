# R9-2 LLM Behavior Rules

## 1. 目的

本書は、UTR-S201向けRAGを参照する生成AIが、多言語実装支援を行う際に守るべき振る舞いを定義する。

対象は日本国内向け、日本語利用者向け、日本の電波法準拠機器向けである。海外利用、海外設置、海外販売は対象外とする。

## 2. すぐコードを書かない条件

生成AIは、以下が不明な場合、すぐにコードを書かず確認質問を行う。

- 対象機器
- 接続方式
- 接続情報
- 読み取り対象
- 読み取り回数
- 既存設定のまま読むか
- 設定変更の可否
- 実機確認環境か机上検討か

## 3. 追加質問すべき条件

以下の場合は、追加質問を行う。

- 読み取りが不安定である
- 読み取り距離を伸ばしたい
- 読み取り速度を上げたい
- 複数タグを読む
- アンテナを指定する
- ログまたはCSV保存が必要
- 周波数、送信出力、Inventory条件の変更が必要になる可能性がある
- FLASH保存など永続設定が必要になる可能性がある

## 4. HOLDにすべき条件

以下の場合はHOLDとする。

- 対象機器が不明
- 接続方式が不明
- PDF正本との照合が必要な仕様を断定できない
- 日本国内仕様から外れる可能性がある
- 海外利用、海外設置、海外販売が示された
- Level 4以上の操作について明示確認がない
- Level 5操作について明示承認と復旧手順がない

## 5. 日本国外利用が示された場合

生成AIは、海外用途が示された場合、国内仕様のまま実装提案しない。

回答では、本RAGは日本国内仕様を前提としており、海外周波数、海外認証、海外販売、海外運用は対象外であることを明記する。

## 6. PDF正本との照合が必要な場合

生成AIは、RAG文書とPDF正本の関係を誤解させてはならない。

- RAGはPDF正本の代替ではない
- PDF原本との全件再照合が未完了の項目は断定しない
- 不明点は要仕様確認またはHOLDとする

## 7. コマンド仕様が不明な場合

生成AIは、コマンド名、識別子、安全分類、レスポンス仕様が不明な場合、推測で補完しない。

特に以下を守る。

- 55h/14h = UHF_InventoryRead
- 55h/15h = UHF_Read
- 55h/14hをUHF_Readと誤記しない
- 55h/15hをUHF_InventoryReadと誤記しない

## 8. Level 4以上の操作が必要な場合

Level 4以上の操作は、生成AIが勝手に実装しない。

対象例:

- 周波数
- キャリアセンス
- 送信出力
- UHF_SetInventoryParam
- Inventory詳細条件

必要な場合は、目的、影響、復旧方法、承認要否を説明し、明示確認を求める。

## 9. FLASH保存が必要な場合

FLASH保存などのLevel 5操作は、明示承認と復旧手順がない場合HOLDとする。

生成AIは、永続設定変更を通常処理として扱わない。

## 10. 多言語移植時の注意

生成AIは、Python専用またはChatGPT専用として扱わない。

対象言語:

- Python
- C#
- C++
- JavaScript / Node.js
- PowerShell

対象AI:

- ChatGPT
- Codex
- Gemini
- Claude
- Copilot
- Cursor
- 社内AI

各言語で、接続、送信、受信、切断、タイムアウト、ログ、例外処理を分けて設計する。

## 11. 実機確認結果の扱い

R8-8Aで確認済みなのは、ROM/status reads、Inventory 1回、タグ応答1件である。

全38コマンドの個別実機送信確認済みとは書かない。

UHF_Read standaloneはHOLDのままとする。

## 12. 誤読しやすいポイント

以下を誤読しない。

- UTR-S201と他シリーズを混同しない
- 55h/14hと55h/15hを混同しない
- 読み取り系と設定変更系を混同しない
- 一時変更と永続設定変更を混同しない
- 国内仕様と海外仕様を混同しない
- RAG文書をPDF正本の代替と扱わない

## 13. 禁止表現

以下の表現は避ける。

- 正式社外公開版
- 正式RC
- 顧客提供版
- 本番利用保証版
- 海外対応済み
- 全コマンド実機確認済み
- PDF正本の代替
- Level 4以上を確認なしで実装可能
- FLASH保存を通常処理として実施可能

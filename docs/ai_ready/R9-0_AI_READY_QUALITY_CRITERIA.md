# R9-0 AI-Ready Quality Criteria

## 1. 目的

UTR-S201 AI補助パッケージを、単なるPDF抽出Markdownではなく、生成AIが誤読しにくい構造化情報として整備する。

## 2. 品質基準

- 表、ビット、チャンネル、周波数、許可/禁止の対応関係を構造化する。
- ファイルサイズ、チャンク分割、検索キーワードの弁別性を改善する。
- 広すぎるYAMLキーワードを見直す。
- 特定AI専用の記述を避ける。
- 特定リポジトリや特定環境に固定しすぎない。
- ChatGPT、Gemini、Claude、Copilotなどを想定する。
- Python、C#、C++、JavaScript、PowerShellなどを想定する。
- 自然言語の依頼に対して、必要な確認質問を行える構造にする。
- 不明点は `HOLD` または要確認にする。

## 3. 安全操作の扱い

危険操作は一律禁止ではなく、必要性、影響、復旧方法、承認条件を明確にする。

ただし、生成AIが勝手にLevel 4以上の操作を実装・実行しないようにする。

## 4. AI非依存方針

RAG文書は特定AIや特定言語に依存しない。各AIや各言語で参照されても、同じ安全境界、同じHOLD条件、同じ確認質問へ誘導できることを目指す。

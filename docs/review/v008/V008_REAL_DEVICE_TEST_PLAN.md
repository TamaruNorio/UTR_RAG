# v008 Real Device Test Plan

## 1. Purpose

全54コマンドについて、今後の実機確認対象・机上確認対象・慎重に扱う対象を分けるための計画である。この文書は実機送信指示ではない。実機確認を行う場合は、対象機器、ROM、接続方式、ログ、復旧方法を記録する。

## 2. Common prerequisites

- 対象機器を記録する
- ROMバージョン読み取りで機種名、シリーズ名、ROMバージョンを確認する
- 接続方式、通信条件、実施場所、実施者を記録する
- 実施前の設定値を読み取り、ログに残す
- ACK/NACK、タイムアウト、複数レスポンス、無応答を区別して記録する
- 復旧方法が不明な操作は実施対象から外す

## 3. Read-only commands

対象例:

- ROM読み取り
- チップバージョン読み取り
- 設定値読み取り
- エラー情報読み取り

確認前提:

- 接続条件とROM判定が完了していること
- 読み取り対象が設定変更を伴わないこと

ログ項目:

- 実行日時
- 対象機器
- ROM/シリーズ
- ACK/NACK
- 取得値

復旧観点:

- 原則として設定復旧は不要
- NACK時はエラーコードを記録する

## 4. RF read commands

対象例:

- UHF_Inventory
- UHF_InventoryRead
- UHF_Read

確認前提:

- アンテナ接続状態を記録する
- 使用タグ、メモリBank、Wordアドレス、Word数を記録する
- 電波送信を伴うことを明確にする

ログ項目:

- キャリア/LBT/アンテナ関連エラー
- タグ応答
- 複数レスポンス
- タイムアウト

復旧観点:

- 読み取り系はタグメモリ変更を伴わない前提で確認する
- 不明な応答はHOLDにする

## 5. Parameter setting commands

対象例:

- SelectParam
- InventoryParam
- ExpandSelectParam
- アンテナ切替
- 出力設定
- 周波数設定
- 動作モード

確認前提:

- 設定前の値を読み取る
- RAM変更かFLASH保存かを明確にする
- 現場で許容される値だけを対象にする

ログ項目:

- 変更前値
- 変更予定値
- 対象機種/ROM
- ACK/NACK
- 復旧値

復旧観点:

- 復旧値と手順が不明な場合は実施しない

## 6. FLASH / persistent settings

対象例:

- FLASH設定値書き込み
- FLASH初期化
- 永続設定に関係する操作

確認前提:

- 変更前設定を保存する
- 復旧方法を事前に確認する
- 実施可否を個別に判断する

ログ項目:

- 対象アドレス/項目
- 変更前後の値
- 復旧方法
- 再起動後の確認結果

復旧観点:

- 復旧不能または影響不明な場合は実施しない

## 7. Antenna switching commands

対象例:

- アンテナ切替設定
- 使用アンテナ番号
- 外部アンテナ自動切替
- 8CH系アンテナ関連設定

確認前提:

- 機種、ROM、4CH/8CH、アンテナ構成を記録する
- 使用するアンテナ番号と自動切替対象範囲を記録する
- 復旧値を確認する

ログ項目:

- 機種
- ROM
- アンテナ構成
- 実行コマンド
- パラメータ
- ACK
- NACK
- エラーコード
- timeout
- 復旧手順

復旧観点:

- 接続されていないアンテナや不明なアンテナ範囲は対象にしない

## 8. Tag memory commands

対象例:

- UHF_Write
- BlockWrite
- BlockErase
- Lock
- Kill
- Encode

確認前提:

- 専用テストタグを使用する
- 対象タグを1枚化またはSelectで特定する
- Access password、メモリBank、Wordアドレス、Word数、書き込み内容を記録する

ログ項目:

- 対象タグ条件
- 書き込み/消去/Lock/Kill対象
- ACK/NACK
- 部分成功リスク
- エラーコード2/3/4

復旧観点:

- Lock、Kill、Erase、Encodeは戻せない可能性を前提に扱う
- テストタグ以外では実施しない

## 9. Lock/Kill/Encode

対象例:

- UHF_Lock
- UHF_Kill
- UHF_Encode

確認前提:

- 専用テストタグを使用する
- 戻せない影響があることを明確にする
- 対象タグ、パスワード、メモリBank、処理対象を記録する

ログ項目:

- 機種
- ROM
- 接続方式
- アンテナ構成
- 実行コマンド
- パラメータ
- ACK
- NACK
- エラーコード
- timeout
- 復旧手順

復旧観点:

- 復旧不能な操作は、本番タグや顧客タグでは実施しない

## 10. Through / advanced commands

対象例:

- UHF_ThroughCmd
- UHF_GetHandle

確認前提:

- ROM対応条件を確認する
- 対象タグ、ハンドル、応答形式を確認する
- 受信ループとタイムアウト処理を設計する

ログ項目:

- ROM/機種
- 対象タグ条件
- 応答形式
- ACK/NACK
- タイムアウト

復旧観点:

- 仕様理解と受信処理が不十分な場合はHOLDにする

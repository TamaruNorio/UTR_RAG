# v008 Human Review Checklist

## 1. Scope

- [ ] 日本国内向けになっているか
- [ ] PDF Ver.1.17前提になっているか
- [ ] no-PDF packageであることが明確か
- [ ] 正式公開版ではないことが明確か

## 2. Command coverage

- [ ] 第6章6.1基準で54件か
- [ ] 6.1.1: 12件か
- [ ] 6.1.2: 31件か
- [ ] 6.1.3: 11件か
- [ ] 7.1/7.2を通常コマンド扱いしていないか

## 3. Command card quality

- [ ] 各カードに目的があるか
- [ ] パラメータ確認項目があるか
- [ ] ACKが整理されているか
- [ ] NACKが整理されているか
- [ ] エラーコード参照があるか
- [ ] 複数レスポンス/無応答/非同期レスポンスが必要に応じて書かれているか

## 4. Policy

- [ ] 仕様書上のコマンドをAIが勝手に禁止していないか
- [ ] PROHIBITEDを乱用していないか
- [ ] アンテナ切替やUHF_SetInventoryParamを使用可能機能として扱っているか
- [ ] ROM読み取りで機種判定する方針になっているか

## 5. Safety / impact

- [ ] RAM/FLASH影響が分かるか
- [ ] 周波数/送信出力/RFキャリア影響が分かるか
- [ ] タグメモリ変更、Lock、Killの影響が分かるか
- [ ] 復旧方法が必要な箇所が分かるか

## 6. Packaging

- [ ] ZIPにPDFが含まれていないか
- [ ] 旧ZIPが含まれていないか
- [ ] nested ZIPが含まれていないか
- [ ] 作業ログが含まれていないか
- [ ] SHA256が一致しているか

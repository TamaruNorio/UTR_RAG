# R9-0 External Release Scope Policy

## 1. 位置づけ

v006 External Review Candidate は、社外向けリリース候補を目指すための確認段階である。

- 正式RCではない。
- 正式顧客提供版ではない。
- 本番利用保証版ではない。
- 社外正式公開には社内承認が必要である。

## 2. 文書の役割

- PDF正本を置き換えない。
- SDK利用可能環境ではSDKを第一候補とする。
- 本RAGは仕様確認、実装検討、サンプル作成、他言語展開の補助である。
- 当社が提供する範囲は、通信仕様、基準実装、注意点、混同防止ルール、実装補助情報までとする。

## 3. 公開形態候補

| 公開形態 | 位置づけ | 主なリスク | 必要確認 |
|---|---|---|---|
| 限定配布 | 相手先を限定した確認用途 | 再配布、誤用、正式版との誤認 | 配布先、利用目的、禁止表現、回収方針 |
| 外部レビュー | 技術レビュー用途 | 指摘管理、版管理、未確認事項の誤解 | レビュー範囲、HOLD事項、回答窓口 |
| 顧客向け評価版 | 評価前提の候補 | サポート期待、実機環境差、導入判断の誤解 | 評価条件、サポート境界、免責、社内承認 |
| Web掲載候補 | 将来公開の候補 | 検索流入、海外利用、PDF正本の代替誤認 | 公開可否、ライセンス、問い合わせ導線、地域範囲 |

## 4. 禁止する扱い

- 正式公開済みと扱わない。
- 正式RCと扱わない。
- 顧客提供版と扱わない。
- 本番利用可能版と扱わない。
- 全コマンド実機確認済みと扱わない。
- PDF正本の代替と扱わない。

# R9-0 Japan Domestic Scope Policy

## 1. 目的

UTR-S201 AI補助パッケージ v006 External Review Candidate に向けて、日本国内向けスコープを明確にする。

## 2. 対象範囲

- 対象は日本国内向けのタカヤ製UTR-S201シリーズである。
- 日本語利用者を主対象とする。
- 日本の電波法に準拠した機器、設定、運用条件を前提とする。
- 周波数、送信出力、キャリアセンス、Inventory条件は国内仕様の範囲でのみ扱う。

## 3. 対象外

- 海外販売
- 海外設置
- 海外運用
- 海外周波数
- 海外認証
- 地域別規制の個別判断

## 4. 生成AIでの扱い

地域条件が不明な場合、生成AIは日本国内仕様を前提に扱う。それ以外の地域条件、認証、周波数、出力、運用条件が関係する場合は `HOLD` とし、仕様確認または社内確認を要求する。

## 5. 安全方針

- 日本国内仕様外の設定変更を提案しない。
- 地域条件が不明なまま周波数、送信出力、永続設定を変更しない。
- 電波法、地域認証、設置条件に影響する可能性がある場合は、生成AIの回答だけで完了扱いにしない。

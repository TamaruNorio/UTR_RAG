# R9-0 License and IP Checklist

## 1. 基本方針

- PDF原本を同梱しない。
- PDF原本をMIT等のOSSライセンス対象に見せない。
- パッケージ内にライセンス表記を置く。
- 自社著作物、サンプルコード、生成AI用文書の扱いを分ける。
- ライセンス方針が未確定の場合は `HOLD` とする。

## 2. 外部公開前チェック

| No | 確認項目 | 判定方針 |
|---:|---|---|
| 1 | PDF原本が混入していない | 必須 |
| 2 | PDF由来の権利表記を誤解させない | 必須 |
| 3 | 自社著作物とサンプルコードのライセンス境界を明記する | 必須 |
| 4 | 生成AI用文書の利用条件を明記する | 必須 |
| 5 | UTR_LAN_Python_CodeX等の関連リポジトリにPDFが混入していないか確認する | 必須 |
| 6 | 公開してよいファイル、公開してはいけないファイルを一覧化する | 必須 |
| 7 | 顧客情報、タグ固有ID、IPアドレス、COMポート実値、社内事情を含めない | 必須 |

## 3. HOLD条件

- ライセンス方針が未確定。
- PDF正本の扱いが未確定。
- 関連リポジトリの混入確認が未完了。
- 公開対象ファイル一覧が未確定。
- 顧客情報、タグ固有ID、IPアドレス、COMポート実値、社内事情の除外確認が未完了。

# R9-0 Support Boundary Policy

## 1. サポート対象外

以下の基本操作は原則としてサポート対象外とする。

- 生成AIの基本操作
- Markdownの基本操作
- RAG登録ツールの基本操作
- GitHubの基本操作
- 利用者固有の開発環境構築

## 2. 当社が提供する範囲

- 通信仕様
- 注意点
- 安全分類
- 混同防止ルール
- 基準実装
- 実機確認済み範囲
- 未確認事項とHOLD事項

## 3. 利用者側で実施する範囲

- 生成コードのレビュー
- 実装環境への適用
- 実機確認
- 異常系試験
- 本番導入判断
- 利用地域、機器構成、タグ条件に応じた最終確認

## 4. READMEに明記すべき文言

- 本資料はPDF正本の代替ではない。
- SDK利用可能環境ではSDKを第一候補とする。
- 生成AIが作成したコードの最終検証は利用者側で行う。
- 実機送信、設定変更、本番導入は利用者側の責任で確認する。
- 日本国内向け、日本語利用者向け、日本の電波法準拠機器向けの候補資料である。
- 海外販売、海外設置、海外運用、海外認証の判断には使用しない。

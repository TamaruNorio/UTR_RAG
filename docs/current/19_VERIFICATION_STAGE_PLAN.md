# 実機確認ステージ計画

## 目的

UTR-S201シリーズのコマンド確認を段階的に進めるための分類です。過去の経緯ではなく、V100で使う確認順序として扱います。

## ステージ分類

| Stage | 内容 | 確認の考え方 |
| --- | --- | --- |
| Stage 0 | 接続確認、ROM読み取り、機種判定 | 最初に行う基本確認 |
| Stage 1 | 設定値の読み取り | 読み取り専用で現在状態を確認 |
| Stage 2 | RFタグ読み取り | タグ、アンテナ、ログ、停止条件を確認して実施 |
| Stage 3 | ランタイム設定変更 | 対象、値、影響、復旧方法を明確にして実施 |
| Stage 4 | RF条件、アンテナ、動作モード | 現場条件と地域条件を確認 |
| Stage 5 | FLASH、永続設定 | 変更前値と復旧手順を必ず残す |
| Stage 6 | タグメモリ操作 | テストタグ、パスワード、復旧可否を確認 |
| Stage 7 | Lock、Kill、Encode、ThroughCmd | 不可逆性や影響範囲を確認して慎重に扱う |

## 補足

仕様書に存在するコマンドを、高影響という理由だけで禁止扱いにはしません。対象機種、ROM、地域条件、現場条件、作業目的を満たす場合は実施対象にできます。

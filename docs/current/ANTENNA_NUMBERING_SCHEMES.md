# アンテナ番号体系の整理

この文書は、UTR-S201 シリーズ通信プロトコル説明書 Ver.1.17 に現れる複数の「アンテナ番号」を、AIとの実装・レビューで混同しないための整理資料です。

公式PDFが一次情報です。この文書は、個別コマンドのPDF該当節を置き換えるものではありません。

## 1. この文書で区別する番号体系

このプロトコルでは、同じ「アンテナ番号」という語でも、用途とフレーム位置により意味が異なります。

| 体系 | 主な出現箇所 | 実装上の扱い |
|---|---|---|
| 内部アンテナ番号 | 使用アンテナ番号の読み取り `55h/48h`、書き込み `55h/38h` | リーダライタ側のアンテナ出力番号として扱う |
| 外部アンテナ番号 | 使用アンテナ番号の読み取り `55h/48h`、書き込み `55h/38h` | 外部アンテナユニット内部のアンテナ番号として扱う |
| RFタグ応答フレームの `ADR` バイト | RFタグデータ応答 `CMD=6Ch`。例: `UHF_Inventory` `55h/10h` | アンテナID出力ON時の読み取りANT番号として扱う。公式アプリ互換表示では生の10進数値として扱う場合がある |

## 2. 内部アンテナ番号

内部アンテナ番号は、リーダライタ側のアンテナ出力番号です。

主に次のコマンドで使われます。

| コマンド | PDF節 | 用途 | 値域・意味 |
|---|---|---|---|
| 使用アンテナ番号の読み取り `55h/48h` | `7.3.6` | 現在選択中、または設定済みの内部アンテナ番号を読む | 8CH仕様のリーダライタでは `00h`=ANT1, `01h`=ANT2, ..., `07h`=ANT8 |
| 使用アンテナ番号の書き込み `55h/38h` | `7.3.7` | 使用する内部アンテナ番号を書き込む | PDF表では `0-255`、`00h`=ANT1, `01h`=ANT2, ..., `FFh`=ANT256。8CH機では実機の出力ポートはANT1からANT8まで |

`55h/48h` は、アンテナポート8ch仕様のリーダライタの場合に有効なコマンドとして整理されています。`55h/38h` では、UTR-SUN02V-8CH / UTR-SUN02-8CH はANT1からANT8までの8つの出力ポートを持つと説明されています。

8CH仕様専用コマンド（`55h/48h`、`55h/38h`、`55h/47h`、`55h/37h` など）を非対応機種（4CH、1CH系）で実行すると、NACK `44h`（`FORMAT_ERROR`）が返る場合があります。これは、引数の値だけが誤っているという意味ではなく、コマンド自体がその機種で未対応であることを示す応答として扱ってください。実装・デバッグ時は、まず対象機種がそのコマンドに対応しているかを `COMMAND_MASTER_V117.md` またはPDF該当節で確認してください。

機種により値域・意味が異なりうるため、内部アンテナ番号を実装で扱う場合は、対象機種とROMバージョンを確認し、使用するコマンドのPDF該当節で値域を個別に確認してください。

## 3. 外部アンテナ番号

外部アンテナ番号は、リーダライタに接続した外部アンテナユニット内部のアンテナ番号です。

主に次のコマンドで使われます。

| コマンド | PDF節 | 用途 | 値域・意味 |
|---|---|---|---|
| 使用アンテナ番号の読み取り `55h/48h` | `7.3.6` | 現在選択中、または設定済みの外部アンテナ番号を読む | `0-31`。`00h`=ANT1, `01h`=ANT2, ..., `1Fh`=ANT32 |
| 使用アンテナ番号の書き込み `55h/38h` | `7.3.7` | 使用する外部アンテナ番号を書き込む | `0-31`。`00h`=ANT1, `01h`=ANT2, ..., `1Fh`=ANT32 |

UTR-SUN02V-8CH は、対応する外部アンテナを接続する場合に限り、外部アンテナユニット内の最大32個のアンテナを切り替えることができます。UTR-SUN02-8CH は外部アンテナの制御ができないため、外部アンテナ番号は `0` 固定で指定します。

外部アンテナ番号は内部アンテナ番号とは別フィールドです。内部アンテナ番号と外部アンテナ番号の組み合わせによって選択されるアンテナの詳細は、PDF該当節で確認してください。

## 4. RFタグ応答フレームの ADR バイト

RFタグ応答フレームの `ADR` バイトは、通常のリーダライタアドレスと同じ位置に現れます。ただし、アンテナID出力ONのRFタグ応答では、リーダライタIDではなく読み取りANT番号になります。

例として、`UHF_Inventory` `55h/10h` のRFタグデータ応答は、次の構造で整理されています。

```text
02 ADR 6C LEN 09 RSSI_MSB RSSI_LSB ANGLE N_PC_EPC <PC+EPC...> 03 SUM 0D
```

この `ADR` バイトは、使用アンテナ番号の読み取り・書き込みで使う内部アンテナ番号や外部アンテナ番号とは別のフレーム位置、別の意味の値です。公式アプリ互換の表示では、この `ADR` バイトを変換せず、生の10進数値としてANT列に表示する場合があります。

`ADR` バイトを `55h/38h` の内部アンテナ番号や外部アンテナ番号へそのまま流用しないでください。RFタグ応答の `ADR` は、アンテナID出力設定、RFタグ応答種別、対象機種に依存して解釈する必要があります。

## 5. 他コマンドのアンテナ番号との関係

`UHF_CheckAntenna` `55h/44h` でもアンテナ番号を指定しますが、機種ごとに値の意味が異なります。

| 機種条件 | `55h/44h` のアンテナ番号 |
|---|---|
| UTR-S201 / UTR-SHR201 | `00h`=ANT0 |
| UTR-SUN02-4CH | `00h`=ANT0, `01h`=ANT1, `02h`=ANT2, `03h`=ANT3 |
| UTR-SUN02V-8CH / UTR-SUN02-8CH | `00h`=ANT1, `01h`=ANT2, ..., `07h`=ANT8 |

このように、コマンドによってANT0起点かANT1起点か、また値域が異なる場合があります。あるコマンドで読めた値を、別のコマンドの引数として使う場合は、同じ体系かどうかを必ず確認してください。

## 6. 実装時の注意

内部アンテナ番号、外部アンテナ番号、RFタグ応答フレームの `ADR` バイトを混同して値をそのまま使い回すと、範囲外の値を書き込みコマンドへ渡す実装ミスにつながります。

特に、RFタグ応答フレームの `ADR` バイトを公式アプリと同じ生の10進数表示として扱う場合、その表示値は `55h/38h` の内部アンテナ番号・外部アンテナ番号へ自動投入できる値ではありません。

使用するコマンドごとに、そのコマンドのPDF該当節に明記された値域、機種条件、フィールド位置を個別に確認してください。断定できない場合は「機種により異なる。PDF該当節で確認」と明記し、独自解釈で値変換を実装しないでください。

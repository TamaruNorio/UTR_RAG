# 実機操作と確認項目

## 1. 基本方針

プロトコル仕様書に存在するコマンドを、高影響という理由だけで禁止扱いにはしません。

周波数変更、送信出力変更、アンテナ設定変更、InventoryParam / SelectParam / ExpandSelectParam 変更、FLASH操作、タグメモリ操作も、対象機種、ROMバージョン、地域条件、現場条件、作業目的を満たす場合は実施対象になります。

## 2. AIに任せない判断

AIが独断で次の判断をしないようにします。

- 作業指示にないコマンドを追加する。
- 周波数、送信出力、アンテナ番号などの設定値を決める。
- NACK、timeout、LBTエラー、アンテナエラーの後に継続判断する。
- 対象機種やROM条件を確認せずに実機送信する。

## 3. 実機送信前に明確にすること

実機送信を行う場合は、次を作業指示として明確にします。

- 対象コマンド
- 対象機種
- ROMバージョン
- 接続方式
- 設定値またはパラメータ
- 実行目的
- 影響範囲
- 復旧方法
- 停止条件
- ログ方針

## 4. 会社判断が必要なもの

以下は、このリポジトリだけで決めません。

- 顧客提供判断
- 社外公開判断
- 海外運用・海外販売判断
- 量産適用判断
- ライセンス / IP確認
- 顧客情報を含むログの取り扱い

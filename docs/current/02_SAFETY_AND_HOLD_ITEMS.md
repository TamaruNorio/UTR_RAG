# 02 Safety and HOLD Items

## 1. 操作レベル

| Level | 概要 | 扱い |
|---:|---|---|
| 0 | 文書確認のみ | 実機操作なし |
| 1 | 読み取り専用に近い確認 | 仕様確認後に限定実施 |
| 2 | RF送信を伴う読み取り | 環境・タグ・ログ条件を確認 |
| 3 | 条件付き操作 | 個別判断 |
| 4 | 設定変更、タグ操作、再起動など影響が大きい操作 | 明示確認が必要 |
| 5 | FLASH、周波数、送信出力など重大影響操作 | 明示承認と復旧手順がない場合HOLD |

## 2. 重要操作の扱い

- FLASH書き込み: Level 5 / HOLDまたは禁止
- 周波数変更: Level 5相当 / 明示承認なしでは実施しない
- 送信出力変更: Level 5相当 / 明示承認なしでは実施しない
- UHF_SetInventoryParam: 自動送信禁止
- 8CHアンテナ切替: 自動切替禁止
- 永続設定変更: 明示承認と復旧手順なしではHOLD

## 3. HOLD事項

- 正式社外公開は社内承認待ち
- PDF原本との全件再照合
- traceability不足項目の補完
- ライセンス/IP方針の最終確定
- UHF_Read standalone
- 全38コマンドの個別実機送信確認
- Level 4以上の実機操作
- Level 5操作
- 海外利用・海外販売

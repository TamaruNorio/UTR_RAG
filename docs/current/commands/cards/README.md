# UTR-S201 コマンドカード

このディレクトリには、UTR-S201 シリーズ通信プロトコル説明書 Ver.1.17 に対応するコマンドカードを格納します。

## 1. 目的

コマンドカードは、AIとのペアプログラミングで以下を確認しやすくするための資料です。

- コマンドの目的
- PDF上の参照章番号
- コマンドバイト、詳細コマンド、サブコマンド
- 読み取り、設定変更、タグメモリ操作などの分類
- 実装前に確認すること
- ACK / NACK / timeout の扱い
- 実機確認時の注意点

## 2. 注意

公式PDFが一次情報です。PDF原本は社内の正式な管理場所から別途準備してください。GitHubにはPDF原本をアップロードしないでください。

各カードの `PDF仕様フィールド定義` には、公式PDFの該当節にあるコマンド表、レスポンス表、値一覧、条件、例を、AIがカード単体で読めるように転記します。実装時はこの節を省略せず確認してください。

公式PDFに掲載済みの完成Hex例は、ACK/レスポンス説明として記載できます。

実機ログ由来のraw EPC / UII / TID、パスワード、顧客固有値を含むHex、または安全確認を省略して実機へそのまま送信できるコードは、このディレクトリには追加しません。

Kill Password / Access Password の具体値は、PDF掲載例であっても `<PASSWORD_BYTES>` などに置き換える場合があります。EPC / UII / TID などタグ固有値に見える値も、`<EPC_BYTES>` や `<TID_BYTES>` などに置き換える場合があります。この場合、その行のSUM値はプレースホルダ置換後の再計算値ではありません。

# V100 最終版 利用ガイド

## このGitの目的

UTR-S201シリーズの通信プロトコル理解、実装支援、レビュー、段階的な実機確認を、AIとのペアプログラミングで進めやすくすることです。

## AIに読ませる範囲

まずREADME、公開範囲、llms.txtと共通資料を確認し、[用途別参照ガイド](TASK_READING_GUIDE.md)から対象カードへ進みます。カードの `related_docs` はすべて確認します。全体監査の場合は全文を対象にしますが、個別用途では不要な全文投入や同一資料の重複読み込みを避けます。

メーカーSDKを必須とせず、公開プロトコルから実装する前提です。現在は[文書整備](../IMPROVEMENT_PLAN.md)を先行し、プログラム改修は後工程です。試験ラベルの意味は[確認状態の記録方針](VERIFICATION_POLICY.md)、未確定の仕様は[原典照合一覧](SOURCE_REVIEW_STATUS.md)を参照してください。

## 実装時に決めること

対象機種、ROMバージョン、接続方式、対象コマンド、実装言語、timeout、ログ方針、実機送信の有無、停止条件、復旧方法を明確にしてください。

## 実機操作の扱い

仕様書に存在し、対象機種、ROM、地域条件、現場条件を満たすコマンドは実施対象にできます。AIが独断で値や継続判断を決めないようにしてください。

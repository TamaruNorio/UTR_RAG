# Stage 0/1 読み取り専用確認キット

## 目的

接続確認、ROM読み取り、設定値読み取りを安全に始めるための確認キットです。設定変更やタグメモリ書き込みを目的としません。

## 確認手順

1. 接続方式を指定する。
2. dry-runで対象コマンドを確認する。
3. 実機確認する場合は `--execute` を指定する。
4. 最初にROMバージョンを読み取る。
5. ROM番号とシリーズ名から機種を判定する。
6. Stage 0の読み取り専用コマンドを確認する。
7. Stage 1の設定値読み取りコマンドを確認する。
8. ACK、NACK、timeoutを記録する。

## 対象外

設定変更、FLASH変更、周波数変更、送信出力変更、アンテナ設定変更、タグメモリ操作、Lock、Kill、Encode、ThroughCmdはこのキットの対象外です。対象外とは仕様上禁止ではなく、この確認キットの範囲外という意味です。

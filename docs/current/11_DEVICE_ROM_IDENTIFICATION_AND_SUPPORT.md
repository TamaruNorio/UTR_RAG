# 機種・ROM判定と対応確認

## 1. 標準フロー

1. リーダライタへ接続する。
2. ROMバージョン読み取りを行う。
3. ROM番号とシリーズ名を解析する。
4. シリーズ名から対象機種を判定する。
5. 対象機種とROMバージョンに対応するコマンドか確認する。
6. 必要なパラメータと現場条件を確認する。
7. 対象コマンドを実装または実機確認する。
8. ACK、NACK、複数レスポンス、完了レスポンス、timeoutを解析する。
9. 結果と停止判断をログに残す。

## 2. シリーズ名と機種の対応

| シリーズ名 | 機種 |
|---|---|
| USM01 | UTR-S201 |
| USM02 | UTR-SUN02-4CH |
| USM05 | UTR-SHR201 |
| USM06 | UTR-SUN02V-8CH |
| USM08 | UTR-SUN02-8CH |

## 3. ROMから分からないこと

ROM読み取りで機種とROMバージョンは確認できますが、以下は現場条件として別途確認します。

- 接続アンテナ本数
- 使用アンテナ番号
- 対象タグ
- メモリバンク、ワードアドレス、ワード数
- 周波数、送信出力、地域条件
- RAMのみの変更か、FLASHへ保存する変更か
- 復旧方法
- 停止条件

## 4. 実装時の注意

対象機種またはROM条件が合わない場合は、独自判断で代替コマンドを送信しないでください。

高影響コマンドであっても、プロトコル仕様書に記載され、対象機種、ROM、地域条件、現場条件を満たす場合は実施対象になります。実施時は、対象、値、影響範囲、復旧方法、停止条件を明確にします。

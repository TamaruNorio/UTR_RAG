# 04 Requirement Clarification

## 1. 自然言語の依頼例

- UTR-S201でタグを読みたい
- C#で読み取りアプリを作りたい
- USB接続でInventory結果をログに残したい
- タイムアウト時に異常終了しないようにしたい

## 2. 最低確認項目

- 対象機器
- 接続方式
- 読み取り対象
- 使用タグ
- アンテナ構成
- ログ保存要件
- CSV出力要否
- 設定変更可否
- 実機確認か机上確認か

## 3. 確認質問テンプレート

```text
実装前に確認します。
1. 対象機器と接続方式は何ですか。
2. 読み取り対象はInventoryですか、特定メモリ読み取りですか。
3. 周波数、送信出力、FLASH、永続設定を変更しない前提でよいですか。
4. ログやCSV出力は必要ですか。
5. 実機確認を行う環境と使用タグは何ですか。
```

## 4. 方針

設定変更可否が不明な場合はHOLDにする。実機確認が必要な内容は、机上確認だけで完了扱いにしない。

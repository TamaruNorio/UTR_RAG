# 要件確認ガイド

## 1. ROMから分かること

ROMバージョン読み取りにより、シリーズ名、対象機種、ROMバージョンを確認できます。

## 2. 現場条件として確認すること

ROMから分からない条件は、作業者または現場条件として確認します。

- 接続アンテナ本数
- 使用するアンテナ番号
- 外部アンテナや自動切替の対象範囲
- 対象タグ
- 読み書きするメモリバンク
- ワードアドレス
- ワード数
- 書き込みデータ
- Accessパスワード条件
- RAMのみの変更か、FLASHへ保存する変更か
- 周波数またはスキャン方式
- 送信出力
- リーダライタ動作モード
- 外部I/Oの用途
- 復旧方法
- 停止条件

## 3. AIへ確認させる質問例

- 対象機種とROMは何ですか。
- 接続方式はUSB、LAN、シリアルのどれですか。
- 実行したい操作は読み取り、設定変更、RFタグ読み取り、RFタグ書き込みのどれですか。
- 実機送信を行いますか。机上確認だけですか。
- 設定変更の場合、変更前の値を読み取って記録しますか。
- 異常時の停止条件と復旧方法は何ですか。

# パラメータ確認ガイド

## 1. ROM読み取りで確認できること

- シリーズ名
- 対象機種
- ROMバージョン

## 2. 作業者または現場条件として確認すること

- 接続アンテナ本数
- 物理アンテナ容量
- 使用するアンテナ番号
- 外部アンテナ自動切替の対象範囲
- アンテナID出力のON/OFF
- TID付加のON/OFF
- EPC/UII応答設定
- EPCバッファリング
- 読取完了応答のON/OFF
- アンテナ切替完了応答のON/OFF
- キャリア検知応答のON/OFF
- 対象RFタグ
- メモリバンク
- ワードアドレス
- ワード数
- 書き込みデータ
- Accessパスワード条件
- RAMのみの変更か、FLASHへ保存する変更か
- 周波数またはスキャン方式
- 送信出力
- リーダライタ動作モード
- 外部I/Oの用途
- 復旧方法
- 停止条件

## 3. 不足している場合の扱い

必要パラメータが不足している場合は、完成Hexや実機送信用コードを作らず、確認リストを返します。

ACK/NACK解析に必要な設定値が不足している場合も同じです。特にInventory系、自動読み取り、アンテナ切替、キャリア検知を扱う場合は、設定読戻しなしで応答データ長やACK内バイトの意味を断定しないでください。

## 4. AIへの依頼例

```text
対象機種、ROM、接続方式、対象コマンド、実装言語、実機送信の有無を確認してください。
不足しているパラメータがあれば、送信用コードを作らず確認リストを出してください。
```

## 5. 注意

プロトコル仕様書に存在するコマンドは、条件が揃えば実施対象になります。ただし、AIが独断でパラメータ値を決めないようにしてください。

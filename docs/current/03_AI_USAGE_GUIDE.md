# AI Usage Guide

1. Read ROM version first when connected.
2. Identify product series and ROM version.
3. Open `09_COMMAND_MASTER_V117.md` and the target command card.
4. Confirm parameters and field conditions using `15_PARAMETER_CONFIRMATION_GUIDE.md`.
5. Review impact using `12_RAM_FLASH_IMPACT_MATRIX.md` and `13_RF_SAFETY_AND_CARRIER_RULES.md`.
6. Parse ACK/NACK using `10_RESPONSE_AND_NACK_MASTER.md`.
7. Keep desk review and real-device confirmation separate.

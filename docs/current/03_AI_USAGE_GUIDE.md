# 03 AI Usage Guide

## 1. 基本方針

AIは依頼を受けてすぐコードを書かない。まず目的、対象機器、接続方式、タグ、ログ、設定変更可否、実機確認範囲を確認する。

## 2. 想定AI

ChatGPT、Codex、Gemini、Claude、Copilot、Cursor、社内AIを想定する。特定AI専用ではない。

## 3. 基本プロンプト

```text
UTR-S201シリーズ向けの読み取りプログラムを検討しています。
日本国内向け、日本の電波法準拠機器向けとして、まず安全確認と要件確認を行ってください。
すぐにコードを書かず、接続方式、読み取り対象、タグ条件、ログ要件、設定変更の有無、HOLD事項を確認してください。
完成Hex、SUM計算済みコマンド、実機送信用コードは生成しないでください。
```

## 4. HOLD時の応答方針

- 不明な仕様はHOLDにする
- Level 4以上は明示確認を要求する
- Level 5は明示承認と復旧手順がない場合HOLDにする
- PDF原本との照合が必要な場合は未確定として扱う

## 5. 禁止表現

- 正式社外公開済み
- 顧客提供可能
- 本番利用保証
- PDF正本の代替
- 海外対応済み
- 全コマンド実機確認済み
- 安全確認完了版

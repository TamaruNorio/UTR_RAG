# 対象範囲と位置づけ

この文書は、UTR_RAG の対象範囲と位置づけを整理します。

## 1. 対象範囲

対象は、タカヤ製 UTR-S201 シリーズの通信プロトコル理解、実装支援、レビュー、段階的な実機確認です。

基準資料は `UTR-S201シリーズ 通信プロトコル説明書 Ver.1.17` です。公式PDFが一次情報であり、このリポジトリは公式PDFを置き換えるものではありません。

## 2. このリポジトリで扱うこと

- コマンド仕様の整理
- ACK / NACK / timeout などの応答処理の整理
- ROMバージョン、シリーズ名、対象機種の確認方法
- AIペアプログラミングで実装・移植・レビューするときの前提整理
- 実機確認時のログ、停止条件、復旧方針の整理

## 3. このリポジトリだけで判断しないこと

- 公式PDFと矛盾する仕様判断
- 顧客提供可否
- 社外公開可否
- 海外運用・海外販売可否
- 量産適用可否

これらは、会社の正式な判断、対象地域の条件、顧客条件、対象機器の状態を確認して決めます。

## 4. 実機操作の考え方

プロトコル仕様書に存在し、対象機種、ROMバージョン、地域条件、現場条件を満たすコマンドは、実装・実機送信の対象にできます。

高影響コマンドを、高影響という理由だけで仕様上禁止扱いにはしません。ただし、AIが独断で対象コマンド、設定値、継続判断を決めないようにします。

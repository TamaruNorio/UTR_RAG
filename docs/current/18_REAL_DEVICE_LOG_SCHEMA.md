# 実機確認ログ項目

## 目的

実機確認時に残すログ項目を整理します。ログは、再現性、原因切り分け、レビュー、顧客説明のために必要です。

## 記録項目

| 項目 | 内容 |
| --- | --- |
| 日時 | 確認を行った日時 |
| 操作者 | 作業者名または識別名 |
| 対象機種 | ROM読み取りから判定した機種 |
| ROMバージョン | ROM読み取り結果 |
| 接続方式 | USB、LAN、シリアルなど |
| 対象コマンド | コマンド名、PDF章番号、コマンドバイト |
| パラメータ | 設定値、タグ条件、アンテナ条件など |
| レスポンス | ACK、NACK、timeout、無応答、複数レスポンス |
| エラー | NACKエラーコード、LBT、アンテナエラーなど |
| 結果 | PASS、FAIL、BLOCKED、NEEDS_RETESTなど |

## GitHubに置かない情報

runtime logs、実CSVログ、顧客情報、実IPアドレス、raw EPC / UII / TID、認証情報はGitHubにアップロードしません。必要な場合はマスクした要約を使います。

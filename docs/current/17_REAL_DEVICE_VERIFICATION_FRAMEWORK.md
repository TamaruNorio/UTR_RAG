# 実機確認フレームワーク

## 目的

UTR-S201シリーズのコマンドを実機で確認するときの共通方針を整理します。実機送信を直接指示する文書ではなく、確認前にそろえる条件、ログ、停止条件、結果判定を明確にするための文書です。

## 標準手順

1. 接続方式を決める。
2. ROMバージョンを読み取る。
3. シリーズ名から対象機種を判定する。
4. 対象コマンドが機種・ROM・現場条件に合うか確認する。
5. パラメータ、影響範囲、復旧方法、停止条件を決める。
6. 実機確認を行う場合はログを残す。
7. ACK、NACK、timeout、LBT、アンテナエラーを分けて記録する。

## AI利用時の注意

AIは実装案やレビュー観点を作れます。ただし、AIがコマンド、設定値、継続判断を独断で決めないようにします。実機送信の有無、許可範囲、停止条件を作業指示に明記してください。

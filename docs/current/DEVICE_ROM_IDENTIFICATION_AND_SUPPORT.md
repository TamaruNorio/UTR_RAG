# 機種・ROM判定と対応確認

## 1. 標準フロー

1. リーダライタへ接続する。
2. ROMバージョン読み取りを行う。
3. ROM番号とシリーズ名を解析する。
4. シリーズ名から対象機種を判定する。
5. 対象機種とROMバージョンに対応するコマンドか確認する。
6. 物理アンテナ容量、接続OKアンテナ、使用アンテナ設定を確認する。
7. [応答マスタのACK解釈の前提](RESPONSE_AND_NACK_MASTER.md)と対象カードに従い、対象応答の解釈に必要な設定を確認する。動作モード、アンテナID出力等の一覧をすべてのACKに必須な一括読戻しとせず、現在のモードで取得できる範囲を確認する。
8. 必要なパラメータと現場条件を確認する。
9. 対象コマンドを実装または実機確認する。
10. ACK、NACK、複数レスポンス、完了レスポンス、非同期レスポンス、timeoutを解析する。
11. 結果と停止判断をログに残す。

自動読み取り中は、モード読取りを含む通常の設定取得が保証されません。p.19–20の受付例外と[モード切替の条件](RESPONSE_MODE_APPLICABILITY.md)を先に確認します。コマンドモードへ戻す操作は動作変更なので、取得できない元設定を推測したり、観測のみの作業に停止を追加したりしません。

## 2. シリーズ名と機種の対応

| シリーズ名 | 機種 |
|---|---|
| USM01 | UTR-S201 |
| USM02 | UTR-SUN02-4CH |
| USM05 | UTR-SHR201 |
| USM06 | UTR-SUN02V-8CH |
| USM08 | UTR-SUN02-8CH |

p.2の対応表を根拠とします。UMP01はUTR-S101シリーズで別説明書の対象です。未知のシリーズ名を既知のUSM機種へ割り当てません。

### バージョン情報の使い分け

[ROM読取り](commands/cards/rom_version_read.md)は制御マイコンの版と5文字のシリーズ名を返します。ACKはLEN=0Ah、DATA[1]がメジャー、DATA[2～4]がマイナー、DATA[5～9]がシリーズ名です。ASCIIの1100USM01はUTR-S201・1.100、2030USM05はUTR-SHR201・2.030です（p.2・145）。

[チップ読取り](commands/cards/55_90_chip_version_read.md)は内蔵チップのFW／チップ名またはシリアルを返します。UR201をUSM01へ変換したり、チップFWをROMの対応条件に代用したりしません。説明書Ver.1.17も別の版です。シリアル欄は10 byteで、製造番号8桁を含みます（p.146–147）。

対応判定では1桁・3桁のROM表現を保持し、数字を検証してメジャー・マイナーの整数の組で比較する設計とします。機種と版を§6.2の表へ当て、複数列に該当すれば最も右の列を参照し、対象コマンド本文の条件も確認します（p.108）。未掲載形式・未知機種に対応保証を拡張しません。

### 初回取得と連続モード

ROM識別を始めるために既知のROMを要求する循環は避けます。接続先と対象資料の候補を確認してROMを取得し、結果で後続処理の適用範囲を絞ります。ROM・チップ読取りは連続モード中の受付例外ですが、各種設定読取りへの保証は広がりません（p.19–20）。チップ取得では00h／01hを明示し、同じ詳細90hのACK/NACKを要求に対応づけます。

ROM応答だけではシリアル番号や設定値を取得したことにはならず、通信確認だけで再起動の実行を証明することもできません。p.147のシリアル応答SUM不一致は[OPEN-024](SOURCE_REVIEW_STATUS.md)で保留しています。

## 3. ROMから分からないこと

ROM読み取りで機種とROMバージョンは確認できますが、以下は現場条件として別途確認します。

- 接続アンテナ本数
- 物理アンテナ容量
- 使用アンテナ番号
- アンテナID出力
- TID付加
- EPC/UII応答設定
- EPCバッファリング
- 読取完了応答
- アンテナ切替完了応答
- キャリア検知応答
- 対象タグ
- メモリバンク、ワードアドレス、ワード数
- 周波数、送信出力、地域条件
- RAMのみの変更か、FLASHへ保存する変更か
- 復旧方法
- 停止条件

## 4. 実装時の注意

対象機種またはROM条件が合わない場合は、独自判断で代替コマンドを送信しないでください。

高影響コマンドであっても、プロトコル仕様書に記載され、対象機種、ROM、地域条件、現場条件を満たす場合は実施対象になります。実施時は、対象、値、影響範囲、復旧方法、停止条件を明確にします。

## 5. UTR-SUN02-4CH / USM02 のアンテナ確認

UTR-SUN02-4CH / USM02 は4CH機として扱います。8CH機向けの使用アンテナ番号コマンドだけで判断せず、4CH機向けのアンテナ切替設定、物理接続状態、実際に観測されたアンテナ番号を併せて確認してください。

実機確認済みの代表条件は以下です。

| 項目 | 確認結果 |
|---|---|
| 対象機種 | UTR-SUN02-4CH / USM02 |
| ROM | 2.052 |
| 物理アンテナ容量 | 4 |
| 自動読み取り使用アンテナ | ANT0, ANT1, ANT2, ANT3 から読戻し可能 |
| 実機確認した自動切替 | ANT0, ANT1, ANT2 |
| TID付加 | OFF/ON差分を実応答で確認 |
| 読取完了応答 | ON時の応答を確認 |
| アンテナ切替完了応答 | ON時の応答を確認 |
| キャリア検知応答 | 設定ONの読戻しを確認。イベント発生は環境依存 |

ACKパーサは、ROM判定だけで完結させず、この起動時スナップショットを参照して応答を分類してください。

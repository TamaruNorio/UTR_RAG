# 機種・ROM判定と対応確認

## 1. 標準フロー

1. リーダライタへ接続する。
2. ROMバージョン読み取りを行う。
3. ROM番号とシリーズ名を解析する。
4. シリーズ名から対象機種を判定する。
5. 対象機種とROMバージョンに対応するコマンドか確認する。
6. 物理アンテナ容量、接続OKアンテナ、使用アンテナ設定を確認する。
7. リーダライタ動作モード、アンテナID出力、TID付加、EPC/UII応答設定、読取完了応答、アンテナ切替完了応答、キャリア検知応答を読戻す。
8. 必要なパラメータと現場条件を確認する。
9. 対象コマンドを実装または実機確認する。
10. ACK、NACK、複数レスポンス、完了レスポンス、非同期レスポンス、timeoutを解析する。
11. 結果と停止判断をログに残す。

## 2. シリーズ名と機種の対応

| シリーズ名 | 機種 |
|---|---|
| USM01 | UTR-S201 |
| USM02 | UTR-SUN02-4CH |
| USM05 | UTR-SHR201 |
| USM06 | UTR-SUN02V-8CH |
| USM08 | UTR-SUN02-8CH |

## 3. ROMから分からないこと

ROM読み取りで機種とROMバージョンは確認できますが、以下は現場条件として別途確認します。

- 接続アンテナ本数
- 物理アンテナ容量
- 使用アンテナ番号
- アンテナID出力
- TID付加
- EPC/UII応答設定
- EPCバッファリング
- 読取完了応答
- アンテナ切替完了応答
- キャリア検知応答
- 対象タグ
- メモリバンク、ワードアドレス、ワード数
- 周波数、送信出力、地域条件
- RAMのみの変更か、FLASHへ保存する変更か
- 復旧方法
- 停止条件

## 4. 実装時の注意

対象機種またはROM条件が合わない場合は、独自判断で代替コマンドを送信しないでください。

高影響コマンドであっても、プロトコル仕様書に記載され、対象機種、ROM、地域条件、現場条件を満たす場合は実施対象になります。実施時は、対象、値、影響範囲、復旧方法、停止条件を明確にします。

## 5. UTR-SUN02-4CH / USM02 のアンテナ確認

UTR-SUN02-4CH / USM02 は4CH機として扱います。8CH機向けの使用アンテナ番号コマンドだけで判断せず、4CH機向けのアンテナ切替設定、物理接続状態、実際に観測されたアンテナ番号を併せて確認してください。

実機確認済みの代表条件は以下です。

| 項目 | 確認結果 |
|---|---|
| 対象機種 | UTR-SUN02-4CH / USM02 |
| ROM | 2.052 |
| 物理アンテナ容量 | 4 |
| 自動読み取り使用アンテナ | ANT0, ANT1, ANT2, ANT3 から読戻し可能 |
| 実機確認した自動切替 | ANT0, ANT1, ANT2 |
| TID付加 | OFF/ON差分を実応答で確認 |
| 読取完了応答 | ON時の応答を確認 |
| アンテナ切替完了応答 | ON時の応答を確認 |
| キャリア検知応答 | 設定ONの読戻しを確認。イベント発生は環境依存 |

ACKパーサは、ROM判定だけで完結させず、この起動時スナップショットを参照して応答を分類してください。

## 4. 安全上の考え方

- プロトコル仕様書に記載されたコマンドは、対象機種・ROM・必要パラメータを確認したうえで使用可能です。
- AI/RAG側が勝手にコマンドを禁止しません。
- 設定変更を伴うコマンドは、変更対象と影響範囲を明記します。
- FLASHや永続設定を変更するコマンドは、変更前の設定読み取り、ログ保存、復旧方法を併記します。
- タグメモリ変更、Lock、Killなどは、戻せない可能性があるため、影響を明記します。
- 本パッケージ作成作業中には実機送信や設定変更を行っていません。
- 完成Hexは含めません。
- SUM計算済みコマンドは含めません。
- 実機送信用コードは含めません。
- PDF原本は含めません。

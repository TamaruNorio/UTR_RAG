# 成果物の扱い

## 現在の考え方

V100では、過去のZIP作成経緯ではなく、現在利用するドキュメントを重視します。過去のZIP成果物はGitHub Release側で確認します。

## PDF原本

公式PDFが一次情報です。PDF原本は社内の正式な配布場所または管理場所から別途準備してください。GitHubにはPDF原本をアップロードしないでください。

## GitHubに置かない情報

runtime logs、実CSVログ、顧客情報、実IPアドレス、raw EPC / UII / TID、認証情報、完成Hex、SUM計算済み送信用コマンド例はGitHubにアップロードしません。
